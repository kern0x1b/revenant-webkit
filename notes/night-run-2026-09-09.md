# The night of 9 September

A log written as the work happened, so progress is visible without reading the
diff. Every number here was measured on the device; where something is not
measured, it says so.

## Rules this run held to

One run is not evidence. Memory is three cold runs of four heavy sites, reported
as a median, because the spread between identical runs on this device is 27-36 MB
and several single-run "improvements" earlier were inside it. Rendering is a
verdict from `tests/device/run.sh`, not a screenshot.

## Closed, with the number that closed it

**Joined emoji compose into one glyph.** A grapheme cluster here was
CoreFoundation's idea of one, and this CoreFoundation is from 2012:
`kCFStringComposedCharacterCluster` knows nothing of the ZWJ sequences Unicode
added from 2015 on, so a family or a profession was shaped as its parts - a
beacon caught the joiner arriving at the shaper alone, in the page's text font.
The character, caret and deletion iterators use the ICU backing now, which is
what every non-Cocoa port uses and which this port builds at version 74. An
astronaut is one 26px glyph where it had been two.

**The system font answers font-weight.** Two faults: `kCTFontWeight*` are
declared `CGFloat` and the compatibility layer defined them as CFStrings, so
every rung was a pointer read as a float; and the numeric weight trait is an
iOS 7 mechanism, so the request also goes through
`CTFontCreateCopyWithSymbolicTraits`. `-apple-system` at 700 is 34.2px against
33.0 at 400, and draws bold.

**Thirteen of the eighteen feBlend modes were erased.** This port re-enables NEON,
which upstream disables on iOS, and `FEBlendNeonApplier` predates the CSS blend
modes: it implements five and writes transparent black for the rest.

**Rounded corners were parabolas** - both bezier control points sat on the corner
vertex in the shim - and uneven ones landed on the wrong corner. WebKit's own
beziers draw them now.

**Gradients fading to transparent went through grey.** Premultiplied
interpolation travels in an options dictionary that this CoreGraphics has no
entry point for; the engine's sampling path does it correctly instead. Measured:
the middle of red-to-transparent is 255,0,0.

**Purgeable decoded images: measured, and left off.** 160.9 MB against 203.4 MB
after four sites - a real 42 MB - and the page that draws one image six hundred
times cropped takes the process down. The measurement and the switch to
reproduce it are in the code.

**`useUnlinkedCodeBlockJettisoning`**: no measurable win, returned to upstream's
default rather than kept on faith.

Smaller, all measured or read from the code: a colour font is taken at its word
about having colour glyphs; variation axes are not read on a CoreText that has
none; `vDSP_vaddi` adds vectors instead of returning success and writing nothing;
a blob bind that answered SQLITE_OK while binding nothing is gone; two feature
readers no longer decide from uninitialised memory; the icon writer uses a colour
space that exists.

## Infrastructure

The tweak is built and packaged by Theos from `packaging/`: `make package` gives
one `.deb` with the loader, the compat dylib, the TLS library, the Settings
bundle and the engine frameworks. Installed on the device and verified.

`tests/device/run.sh` runs pages in the browser on the phone; each page reports
its own verdicts and the runner reads them out of the serving HTTP server's log.
21 pass, 3 fail, and the three are one documented defect.
